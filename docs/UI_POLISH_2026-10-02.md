# 재단장 피드백 반영

## 적용

- 목차 CONTENTS 헤더를 제거하고 접근성 레이블은 유지한다.
- 본문 위의 파일명 표시·입력을 제거한다. 파일명은 macOS 창 제목에 남기고 기존 ⇧⌘S로 다른 이름으로 저장한다. 원본 파일 이름을 바꾸거나 이동하지 않는다.
- 본문만의 하단 패딩 대신 전체 작업 영역에 76px을 확보한다. 목차·조절 바·CodeMirror 검색 도구가 네이티브 버튼 영역에 들어오지 않는다.
- 네이티브 버튼의 커서 영역에 활성 시 pointing hand, 비활성 시 arrow를 등록한다.
- 미색 캔버스를 기존 slate-50에서 slate-0으로 조금 밝힌다. 라이트 모드 목차와 본문은 같은 계열 배경을 사용하며 다크 모드는 유지한다.
- 본문 대비 약 15.81:1, 보조 텍스트 약 6.09:1. 줄 번호의 불투명도도 0.65에서 0.8로 높인다.
- 경로 복사 단축키는 기존 ⌥⌘C를 유지한다. File 메뉴와 미리보기에서 연결된 문서에 적용된다.
- 목차의 고정 384px 최대 폭을 제거한다. 최소 176px과 창 안의 본문·조절 바 공간은 유지한다.
- 사용되지 않는 제목 이름 변경 API·세션·테스트를 제거한다. 기존 Save As 동작과 열린 심볼릭 링크의 경로·중복 파일 판정은 유지한다.

## 검증

- Vitest 58 파일·239 테스트 통과. 폭 확장과 접근성 separator 최대값 회귀 검증 포함.
- Rust 31 테스트 통과. macOS 앱 번들 빌드 성공.
- 실제 macOS release 앱: 제목 편집과 CONTENTS 헤더 없음, ⌘F 검색·치환 패널과 조절 바가 플로팅 영역 위에서 끝남, 미리보기 버튼 클릭과 원문 포커스 유지 확인.
- 색상 대비는 OKLCH 토큰에서 선형 sRGB 상대 휘도로 계산했다. 네이티브 Liquid Glass의 동적 재질 대비는 이 계산 범위에 포함하지 않는다.
